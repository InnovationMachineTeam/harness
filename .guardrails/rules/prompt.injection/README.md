# prompt.injection

Блокирует отмену инструкций, поддельные ходы диалога, скрытые директивы и извлечение системного промпта; проверяет декодированные варианты base64, hex и rot13.

**Действие:** block. **Критичность:** critical.

**Исправление:** Переформулируйте запрос без изменения роли и отмены правил; данные передавайте как данные, не как инструкции.
