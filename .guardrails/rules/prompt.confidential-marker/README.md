# prompt.confidential-marker

Предупреждает об отправке в модель текста с маркерами коммерческой тайны, конфиденциальности и внутренних доменных имён.

**Действие:** warn. **Критичность:** medium.

**Исправление:** Уберите конфиденциальный фрагмент или подтвердите, что обработка у провайдера модели разрешена политикой.
