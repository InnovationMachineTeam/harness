# content.write-secret-value

Блокирует запись содержимого с ключами провайдеров, приватными ключами, JWT и строками подключения с паролем.

**Действие:** block. **Критичность:** critical.

**Исправление:** Вынесите значение в переменную окружения или менеджер секретов; в файле оставьте ссылку вида process.env.
