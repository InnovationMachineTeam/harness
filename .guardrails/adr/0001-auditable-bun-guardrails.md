# ADR-0001: аудируемый движок Guardrails на Bun

Статус: принято.

## Решение

Один Bun-движок обслуживает runtime hooks, вызовы из кода, Git hooks и CI. Метаданные правила и исполняемый matcher находятся в одном каталоге. Генератор выпускает отдельные карточки и сводные отчёты. Критический сбой блокирует действие.

## Причины

Прежний Node-скрипт не имел полного тестового покрытия, машиночитаемого реестра интеграций и интерфейса аудитора. Раздельные описания могли расходиться с кодом.

## Последствия

Для запуска нужен Bun. Любое правило требует hit/pass/edge кейсов. Изменение wiring требует записи в реестре. Старый `.agents/runtime/guard.mjs` остаётся только для истории миграции и не используется активными адаптерами.
