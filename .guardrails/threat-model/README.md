# Модель угроз

Guardrails проверяет вызов до исполнения и ограничивает операции с необратимым, секретным, инфраструктурным или управленческим эффектом.

Защищаемые активы: рабочее дерево, история Git, секреты, базы данных, инфраструктура, production-среды, решения человека и целостность самой политики. Доверенная граница включает Bun-процесс Guardrails, исходники каталога и адаптер конкретного runtime.

Основные угрозы: разрушительная команда, обход через другое имя инструмента, обфускация Unicode или percent encoding, повреждённый payload, fail-open адаптер, самоодобрение агента и рассинхронизация документации с кодом.

Остаточные риски:

- Kimi требует ручного зеркала пользовательского конфига; репозиторий проверяет только источник зеркала.
- Статические правила не определяют намерение произвольной программы после запуска.
- Символические ссылки и изменения среды после проверки контролируются sandbox и правами хоста.
- Предупреждение не останавливает вызов; оно предназначено для действий с обратимым эффектом.

Компенсирующие меры: fail-closed для критических интеграций, тесты hit/pass/edge, policy digest, pre-commit, pre-push, CI и интерфейс аудитора.
