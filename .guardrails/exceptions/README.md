# Исключения

Исключение не отключает правило глобально. Каждая запись должна содержать rule id, узкую область, владельца, обоснование, дату окончания и ссылку на решение человека. Просроченное исключение недействительно.

Текущая версия политики не содержит активных исключений. Новое исключение добавляют отдельным JSON-файлом по `schemas/exception.schema.json` и покрывают тестом области действия и срока.
