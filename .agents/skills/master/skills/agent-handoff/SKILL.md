# Передача работы

Заверши серию изменений так, чтобы следующий исполнитель понял состояние без пояснений. Следующий агент не имеет контекста этой сессии: пиши заметки как самодостаточный документ.

## Порядок работы

1. Закоммить завершённое: изменения, прошедшие проверки, оформи отдельными коммитами по формату репозитория; частичный код без рабочей задачи не оставляй.
2. Зафиксируй незавершённое: TODO-комментарии в коде (что осталось, почему остановился), обнови задачи в работе; принятые решения и их причины запиши рядом.
3. Подведи итог сессии: что сделано (конкретно, с именами файлов и команд), что осталось (в шагах), какие блокеры встретились и как их обойти.
4. Убери за собой: удали отладочный код и временные файлы из .agents/.tmp, рабочие копии не оставляй; worktree удаляй только штатной командой репозитория (worktree:remove), не вручную.
5. Оставь заметки следующему исполнителю: с чего начать, какой контекст нужен (файлы, документация, задачи), какие проверки запускать.

## Правила

- Оставляй репозиторий в рабочем состоянии: проверки проходят или причина падения описана явно.
- Разделяй завершённое и идущее: коммит против TODO, без смешения.
- Заметка самодостаточна: имена файлов, команд и причин вместо отсылок "как обсуждали".
- Не оставляй незакоммиченный отладочный код.
