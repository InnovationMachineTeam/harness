# UI-kit проекта

Правила интерфейса для web и mobile. Источник токенов - DESIGN.md в корне; реестр компонентов - design/components.json.

## Общие правила

- Примитивы интерфейса живут в одном модуле кита; экраны собираются только из примитивов кита.
- Новые визуальные свойства вводятся через токены DESIGN.md, а не отдельными значениями.
- Компонент, появившийся в коде, добавляется в design/components.json (платформа web или mobile); компонент - PascalCase-файл или папка с index.tsx в src/uikit/components; компоненты кита вне типовых каталогов регистрируются кнопкой "Зарегистрировать кит".

## Web

- Стек: React + Next.js + Tailwind; цвета и радиусы - семантические классы из токенов проекта (--design-*).
- Примитивы - uikit/components/UIKit/index.tsx (импорт @/uikit); нативные элементы форм используются только внутри примитивов кита.
- Подсветка синтаксиса - highlight.js с темой на токенах (.hljs-* в globals.css); редактор markdown - uikit/components/MarkdownEditor.
- Иконки - lucide-react.

## Mobile

- Раздел заполняется при появлении mobile-приложения (React Native; StyleSheet из токенов).
