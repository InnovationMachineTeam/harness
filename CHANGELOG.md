# Changelog

Изменения репозитория по версиям. Правило ведения: изменение, попадающее в релиз, фиксируется записью в этом файле в той же серии коммитов; запись пишется одной строкой без переноса внутри предложения. Смена файла `VERSION` запускает авто-релиз: workflow `auto-release` создаёт тег `v<версия>` и GitHub Release с автоматическими заметками. Формат даты - ГГГГ-ММ-ДД.

## 0.1.0 - 2026-10-10

Базовая версия: консоль управления рантаймами, сессиями и провайдерами, guard-политика на шесть рантаймов, мастер-навыки и workflow, диспетчер инструментов, индексы и верификация.

- fix(console): зеркала навыков Cursor вместо симлинков - Cursor не следует симлинкам в каталогах навыков.
- feat(skills): процессные навыки agent-start, self-review и agent-handoff.
- feat(guardrails): команда context - машиночитаемые настройки рантайма в JSON.
- feat(harness): подкоманда skill-links - аудит доставки навыков и сгенерированных команд.
- feat(console): режим спринта на странице прогона - задачи по корзинам и шаги задач.
- feat(console): фильтр карточек рантаймов и провайдеров по стране со счётчиками.
- fix(console): корзина CH переименована в CN (Китай) с переназначением провайдеров.
