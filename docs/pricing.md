# Каталог цен: подписки и API моделей

Каталог цен консоли - внешние файлы в `.agents/pricing/` (коммитятся в репозиторий). Интерфейс только читает их; обновление - кнопка "Обновить цены" на вкладке "Настройки - Обновить" (с подтверждением) или правка файлов.

## Файлы

- `subscriptions.json` - тарифы подписок. Разделы `vendors` (вендоры рантаймов, ключ - id рантайма) и `providers` (провайдеры консоли, ключ - id пресета). У каждого: `label`, `site`, `payg` (доступность Pay as You Go и примечание) и `plans[]`: `id`, `name`, `period` (`month`, `quarter`, `halfyear`, `year`), `price`, `currency`.
- `models.json` - API-цены моделей. Ключ - id модели в нижнем регистре; `aliases[]` - отображаемые имена из конфигов рантаймов (`"Claude Opus 5"`). `prices[]` - точка цены у провайдера: `provider` (id провайдера консоли), `official` (цена официального провайдера модели), `inputPerMtok`, `outputPerMtok`, `cacheReadPerMtok` (USD за миллион токенов), `source`, `asOf`, `note`. Средняя цена (`average`) вычисляется при чтении, в файле не хранится.
- `sources.json` - зафиксированные источники. Запись: `url`, `kind` (`api` | `subscriptions`), `format` (`html` | `json`), `target`, `status` (`ok` | `unavailable`), `lastCheckedAt`, `lastError`, `discoveredAt`. Если файла нет, при первом refresh реестр создаётся из списка по умолчанию в `core/pricingCatalog.ts` и фиксируется: дальнейшие обновления идут только по известным источникам.

## Правило эффективной цены

Для расчётов и сравнения (`effectiveModelPrice` в `core/pricingCatalog.ts`):

1. цена официального провайдера модели (точка с `official: true`);
2. если официальной нет - средняя по всем точкам `prices[]`;
3. модели нет в каталоге - токены без стоимости (coverage), как и раньше.

Расчёт - чистые функции `effectiveModelPrice`/`modelEntry` в `core/pricingCatalog.ts` (модуль без node-импортов, доступен UI); чтение и refresh - `core/pricingCatalogServer.ts`. По этому правилу считается стоимость в `/api/stats` и heatmap-метрика `cost`. Если модель отсутствует в каталоге, используется price card рантайма (`.agents/runtime/<id>/config.json`) - прежний механизм `pricedUsage` в workflow не менялся.

## Обновление из источников

`POST /api/pricing/refresh` обходит `sources.json` батчами по 4 с таймаутом 10 с:

- формат `json` - каталог парсится и обновляет цены (сейчас: каталог моделей OpenRouter `https://openrouter.ai/api/v1/models` добавляет точки `provider: openrouter` для моделей, уже существующих в `models.json`);
- формат `html` - проверка доступности; значения цен такими источниками не обновляются, правка чисел выполняется в файлах каталога. Любой HTTP-ответ (включая 403/429) считается "источник отвечает"; ошибка сети или таймаут переводят источник в `unavailable`.

Недоступный источник не останавливает остальные: его данные остаются прежними, вкладка "Обновить" показывает предупреждение. Даты обновления - `updatedAt` в `subscriptions.json` и `models.json`; строка "Цены подписок и моделей" на вкладке "Обновить" показывает последнюю дату и статусы источников (`GET /api/pricing`).

## Выбор подписки и Pay as You Go

Выбор хранится в `state.json` (`settings.billing`): `runtimes` и `providers` - `{ mode: "none" | "plan" | "payg", planId? }`; `deposits` - пополнения Pay as You Go по ключу `runtime:<id>` или `provider:<id>` (`id`, `amount`, `currency`, `at`, `note`). Радио-механизм: по умолчанию "Нет подписки"; Pay as You Go - отдельная опция рядом с тарифами. API - `PUT /api/settings { billing }` (частичный merge по разделам).

UI: вкладка "Подписки" страницы рантайма (`components/runtime/BillingPanel.tsx`) и кнопка-иконка на карточке провайдера (`components/pricing/ProviderBillingModal.tsx`, показывается при наличии тарифов или PAYG в каталоге). Таблица "Стоимость API (справочно)" в обоих местах - цены моделей каталога: официальная, средняя, число источников.

## API

- `GET /api/pricing` - каталог целиком: подписки, модели со средними, статусы источников.
- `POST /api/pricing/refresh` - обновление из источников; ответ: `checked`, `ok`, `unavailable[]`, `modelsUpdated`, `checkedAt`.

Проверенные значения каталога соответствуют публичным прайсам на дату `asOf` (октябрь 2026); источник каждого числа - поле `source`. Модели без подтверждённого прайса внесены с пустым `prices[]` и показываются как "нет данных".
