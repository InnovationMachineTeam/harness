# Документация harness и Agentic OS Console

Документация репозитория `harness`: архитектура консоли, модульная система рантаймов, MCP-синк, плагины, навыки, сессии и эксплуатация. Пользовательский гид по запуску - в [`apps/console/README.md`](../apps/console/README.md); канонические правила работы агентов - в [`AGENTS.md`](../AGENTS.md).

## Карта документов

## Что где искать

- **"Как устроено X?"** → architecture.md, затем профильный документ.
- **"Добавить новый рантайм / навык / плагин / MCP-сервер"** → соответствующий документ содержит пошаговые инструкции.
- **"Почему консоль пишет в мой конфиг?"** → mcp.md (правило managed-имён) и skills.md (оверлеи без правки файлов).
- **Таблицы-справочники** (сигналы рантаймов, форматы таргетов, resume-команды) приведены в профильных документах и дублируются только ссылками.

## Поддержание в актуальном состоянии

Правила поддержки закреплены в `AGENTS.md §11` - кратко:

- документация обновляется **в той же серии коммитов, что и фича**;
- устаревшая документация считается багом: заметили расхождение - исправьте или зафиксируйте TODO и сообщите пользователю;
- при смене структуры документов обновите этот индекс.
